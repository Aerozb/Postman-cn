# 跨平台兼容性核对

2026-09-08 对 **Postman 12.27.0 官方 x64 包**做了静态核对。Windows 使用当前安装的英文原版备份；[macOS ZIP](https://dl.pstmn.io/download/version/12.27.0/osx_64) 和 [Linux tar.gz](https://dl.pstmn.io/download/version/12.27.0/linux_64) 从官网下载，分别为 208510828 和 200473990 字节。

| 平台 | 应用内容位置 | `keytar.node` 等原生模块 |
|---|---|---|
| Windows x64 | `app-12.27.0/resources/app.asar` | Windows PE |
| macOS x64 | `Postman.app/Contents/Resources/app.asar` | macOS Mach-O |
| Linux x64 | `Postman/app/resources/app/`，已展开的目录 | Linux ELF |

三个样本的 `package.json` 均为 Postman 12.27.0，但内容与依赖并不相同：Windows 包含 Windows 的终端、凭据存储等原生组件，macOS / Linux 搭配的是各自平台编译的模块。Linux 官方样本甚至没有 `app.asar`。

## 使用结论

- **其他 Windows x64 电脑**：官方 Squirrel 安装通常同样使用 `app-<版本>/resources/app.asar`；安装根路径可以不同。手动替换要求 Postman 版本一致，脚本会自动发现安装位置。绿色版保持独立目录结构。
- **跨系统**：目录名称或界面相似不代表整份包可互换。当前发布的 Windows `app.asar` 和绿色版不用于 macOS / Linux。
- **可复用部分**：`payload/zh-localize.js` 的词典和 DOM 翻译思路；后续跨平台支持需在各平台原版上注入、保留对应依赖，并适配偏好路径、更新逻辑、打包和 macOS 签名。

本轮没有在 macOS / Linux 上启动应用；以上是官方包的结构和二进制格式核对，不是跨平台运行验证。ARM64 及 Snap / Flatpak 等其他发行形式不在本轮样本范围内。
