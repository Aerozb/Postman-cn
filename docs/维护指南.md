# 维护指南

面向维护者和贡献者。普通用户只需要运行根目录的 `postman-zh.bat`。

## 统一入口

所有常用操作都从根目录入口执行：

```powershell
.\postman-zh.bat help
.\postman-zh.bat install
.\postman-zh.bat restore
```

入口内部按用途调用 `scripts\internal`、`scripts\audit`、`scripts\runtime` 和 `scripts\data` 中的实现。不要再新增根目录 `.bat` 或转发用 `.ps1`。

## 发布前检查

```powershell
Get-ChildItem .\payload,.\scripts -Recurse -File -Filter *.js | ForEach-Object { node --check $_.FullName; if ($LASTEXITCODE) { throw "JavaScript 语法错误：$($_.FullName)" } }
Get-ChildItem .\scripts -Recurse -File -Filter *.ps1 | ForEach-Object { [scriptblock]::Create((Get-Content -Raw -Encoding UTF8 $_.FullName)) | Out-Null }
.\postman-zh.bat help
.\postman-zh.bat install
git diff --check
```

安装脚本会在找不到补丁锚点时失败，不会假装安装成功。验证通过时必须看到：

```text
[Postman 汉化] 验证通过
```

## 添加漏翻译

主要改 `payload\zh-localize.js`：

- 固定完整文案放入 `EXACT`。
- 可组合片段放入 `PHRASES`。
- 带数字、时间或名称变量的文案放入 `RULES`。
- 输入框默认值同时检查 `EDITABLE_EXACT`。
- 原生菜单词条改安装脚本中的菜单包装器，并且中文使用 `\u` 转义。

改完后运行：

```powershell
.\postman-zh.bat install
```

不要直接修改 `app.asar.unpacked.zh`，安装脚本每次都会从 `app.asar.original` 重新解包。

## 审计

审计脚本位于 `scripts\audit`，统一通过入口调用：

```powershell
.\postman-zh.bat scan --max-clicks 120 --delay-ms 180
.\postman-zh.bat audit lightweight
.\postman-zh.bat audit new-request --tabs docs,params,auth,headers --skip-final-sweep
.\postman-zh.bat audit deep-areas
```

只把完整英文短语或混合未翻译片段当作问题；`GET`、`POST`、`API`、`HTTP`、`JSON`、`Git`、快捷键和产品名等技术词可以保留。

## 发布到 GitHub

发布脚本位于 `scripts\maintenance\发布中文版.ps1`，也可从统一入口调用：

```powershell
.\postman-zh.bat publish -CheckOnly
.\postman-zh.bat publish -SkipRelease
```

发布前请确认 `app.asar` 已由统一入口重新打过汉化补丁。不要提交 `app.asar`、`app.asar.original`、`app.asar.unpacked.zh`、`_generated` 或带本机路径的审计产物。
