# 脚本目录

普通用户不要直接运行这里的文件，请使用仓库根目录的 `postman-zh.bat`。

| 目录 | 用途 |
|---|---|
| `postman-zh.ps1` | 解析统一入口命令并分发到下列实现。 |
| `internal/` | 安装、还原、启动、停止和系统修复。 |
| `audit/` | CDP 点击、悬停、右键和弹窗审计。 |
| `runtime/` | 运行时漏翻收集和更新页探测。 |
| `data/` | 静态文案扫描和译文合并。 |
| `maintenance/` | GitHub 发布和打包。 |
| `verify-postman-zh.js` | 安装完成后的综合验证。 |

添加新能力时，优先给 `postman-zh.ps1` 增加子命令，并把实现放入对应分类目录。不要在仓库根目录增加新的 `.bat` 或 `.ps1` 入口。
